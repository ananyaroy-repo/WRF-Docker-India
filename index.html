Project Summary

This project presents a Dockerized workflow for configuring and running the Weather Research and Forecasting (WRF) model. It integrates automated domain configuration, preprocessing utilities, visualization tools, and a browser-based graphical user interface (GUI) to simplify regional weather simulations and improve reproducibility across computing environments.
